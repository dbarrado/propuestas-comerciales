# Propuestas comerciales — skill para Claude

Arma propuestas comerciales en Word con la marca, los precios y los servicios de tu empresa, para clientes empresa (B2B) o particulares (B2C). Busca tus datos en la carpeta del proyecto y te pregunta lo que falta; no inventa.

## Cómo instalarla

1. Descargá **[propuestas-comerciales.zip](https://github.com/dbarrado/propuestas-comerciales/releases/latest/download/propuestas-comerciales.zip)**.
2. En Claude: **Personalizar → Skills → + → Subir una skill**, y elegí el ZIP (sin descomprimirlo).

En Claude Code también podés pedirle al agente: *«Instalá como skill de este proyecto la skill de https://github.com/dbarrado/propuestas-comerciales»*.

## Cómo usarla

Pedí: *«Armá la propuesta para [cliente]»*.
